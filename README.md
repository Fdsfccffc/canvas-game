# 合成四连

一款基于 Canvas 与 Matter.js 的物理合成 H5 小游戏。相同连数的棋子碰撞后会合成下一阶，完整顺序为：

`一连 → 二连 → 三连 → 五连 → 六连 → 七连 → 八连 → 九连 → 十连 → 十一连 → 十二连 → 四连`

下一枚棋子从一连、二连和三连中按权重随机产生。四连是最终、最大的棋子，由两枚十二连合成，出现时即获胜。

当任意棋子的上沿接触或越过红色虚线后，会启动 5 秒危险倒计时。倒计时期间棋子离开红线区域即可解除警报；持续超过 5 秒则结算本局。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 操作

- 电脑：移动鼠标并点击投放；也可使用左右方向键调整落点，空格或回车投放。
- 手机：在棋盘上移动手指调整落点，松手投放。

最佳分数、已解锁连谱和音效偏好会保存在浏览器本地。
